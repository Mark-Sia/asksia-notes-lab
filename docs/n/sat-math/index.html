⚠️8 traps · 陷阱

  1. Read what is ASKED: if it wants 6x − 3, solve for 6x − 3 directly, not x.
  2. SPR answers: no percent sign, dollar sign or commas. 3/4 or 0.75 both fine.
  3. Squared both sides or cleared a fraction? Check for extraneous roots.
  4. Inequality sign flips only on × or ÷ by a negative — not on adding a negative.
  5. "No solution" = parallel lines (same slope, different intercept); "infinitely many" = the same line.
  6. Questions run roughly easy → hard inside a module: bank seconds early to protect the back.
  7. Adaptive panic: a hard Module 2 means Module 1 went WELL. Keep going.
  8. The reference sheet has gaps (no quadratic formula, no slope) — those are yours to memorise.

✅Test-day pacing · 考场节奏

  1. R&W first (64 min) → 10-min break → Math (70 min)
  2. Set the module clock: 22 Q in 35 min, checkpoint at Q11 = 17 min
  3. Stuck > 90 s → flag, guess, move on; come back with leftover time
  4. Desmos for graphs & systems; type equations, read the intersection
  5. Last 2 minutes: every flagged question gets an answer — no blanks

✎ Never leave a blank. Flag & move. Read what is ASKED ✎
